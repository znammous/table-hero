# جدول الأبطال

صفحة يسجّل فيها الأطفال مهام البيت، ويوافق عليها ولي الأمر، مع لوحة إنجاز وشارات وبطل الشهر.
أسماء الأطفال والمهام ونقاطها واسم التطبيق ورمز ولي الأمر تُضبط من زر ⚙️ الإعدادات داخل الصفحة.

**الموقع:** https://znammous.github.io/table-hero/

والنسخة نفسها أيضاً على: https://tablehero-d582b.web.app

## كيف يعمل

- **Firebase Authentication:** ولي الأمر يسجّل دخوله بحساب Google مرة واحدة على كل جهاز.
- **Cloud Firestore:** كل عائلة لها مستند `families/{uid}` فيه الإعدادات والجوائز والرمز، وتحته `entries` للتسجيلات.
- **قواعد الحماية** (`firestore.rules`): لا يقرأ ولا يكتب في بيانات العائلة إلا ولي أمرها، أو ولي أمر آخر أضافه.
- **ولي أمر آخر:** من ⚙️ الإعدادات ← «أولياء الأمور» يكتب ولي الأمر اسمه (مثل أم محمد) فيظهر رمز QR صالح لعشر دقائق ولمرة واحدة. يمسحه الجوال بالكاميرا، أو يكتبه في «ولي أمر آخر؟ انضم برمز»، فيدخل الجدول بلا حساب Google ويُسجَّل في `families/{uid}/guardians/{معرّفه}`. ويُزال من نفس المكان.
- **الاستضافة:** ملف `index.html` ومجلد `fonts` في جذر المستودع، ويعرضهما GitHub Pages و Firebase Hosting.

## النشر

```bash
git push origin main                    # GitHub Pages
firebase deploy --only hosting          # Firebase Hosting
firebase deploy --only firestore:rules  # قواعد الحماية
```

## ملفات قديمة

- `apps-script/Code.gs` نسخة Google Sheet السابقة، محفوظة كمرجع ونسخة احتياطية.
